## 📁 Featured Projects

### 🏥 CareSync: Healthcare Diagnosis & Recommendation App
`Python` `Streamlit` `Scikit-learn` `Pandas` `Plotly` `SQLite`

- Predicts **755 disease classes** from **133 symptoms**, trained on **246,945 records**
- **83.7% test accuracy** and **83.9% weighted F1** (best of 3 competing models)
- Full pipeline: SelectKBest (377 → 200 features) → StandardScaler → PCA (180 components, 95% variance) → Streamlit
- Drug recommendation engine: **53,766 entries, 2,637 drugs, 708 conditions**
- Modular design with PBKDF2-SHA256 authentication and SQLite persistence

🔗 [View repository](https://github.com/shubhamrajsinha11)

### 🌫️ Air Pollution & Respiratory Disease Correlation Dashboard
`Python` `Streamlit` `Pandas` `Matplotlib` `Seaborn`

- Analyzed **14,400 records** (2018-2025) across **10 cities, 5 states** in North India
- Studied Asthma, Dengue and Heat Stroke: **37.3M+ affected cases**
- Statistical testing: **Pearson r = 0.628, p < 0.001, R² = 0.394**
- EPA-standard AQI for 6 pollutants with live OpenWeatherMap API integration
- Risk scoring engine, live AQI gauge, correlation heatmaps, city-wise trends

🔗 [View repository](https://github.com/shubhamrajsinha11)
